Guia do Desenvolvedor

Tudo o que você precisa para personalizar seus módulos gerados.

Instalação

  1. Faça login no painel de administração do Joomla
  2. Vá para Sistema > Instalar > Extensões
  3. Faça upload do arquivo ZIP do módulo
  4. Vá para Sistema > Gerenciar > Extensões > Módulos
  5. Configure o módulo recém-instalado.

Personalizando o Template (default.php)

O arquivo de template está localizado em mod_seumodulo/tmpl/default.php.

<?php
defined('_JEXEC') or die;
$greeting = $params->get('greeting', 'Olá, Mundo!');
if (!$list) return;
?>
<div class="modulo-personalizado">
    <h3><?php echo $greeting; ?></h3>
</div>

Modificando o Helper

Localizado em mod_seumodulo/src/Helper/SeumoduloHelper.php.

public function getItems(Registry $params, SiteApplication $app) {
    $db = $this->getDatabase();
    $query = $db->getQuery(true)
        ->select('a.id, a.title')
        ->from('#__content AS a')
        ->where('a.state = 1')
        ->setLimit($params->get('count', 5));
    $db->setQuery($query);
    return $db->loadObjectList();
}

Subforms Inline

Installation

  1. Log in to your Joomla administrator panel
  2. Go to System > Install > Extensions
  3. Upload the module ZIP file
  4. Go to System > Manage > Extensions > Modules
  5. Configure your module.

Customizing the Template (default.php)
